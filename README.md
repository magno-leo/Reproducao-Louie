# 🎨 Louie — Reprodução de Layout (Colorlib)

Projeto desenvolvido como atividade proposta pelo professor de Front-end, com o objetivo de reproduzir o layout "Louie", template disponibilizado pela Colorlib, utilizando HTML e CSS.

## 📌 Sobre o projeto

A atividade consistia em pegar um layout de referência pronto e recriá-lo do zero, treinando leitura visual de design, estruturação de HTML semântico e estilização em CSS, buscando fidelidade ao template original.

## ✨ Elementos reproduzidos

- 🧭 Cabeçalho / menu de navegação
- 🖼️ Seção hero / banner de destaque
- 📄 Seções de conteúdo do template
- 🦶 Rodapé

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Motivação

Atividade acadêmica com o objetivo de treinar a habilidade de replicar layouts existentes com precisão, reforçando conceitos de estruturação de página, espaçamento, tipografia e organização de CSS a partir de uma referência visual real.

## 🔗 Referência

Layout original: [Louie — Colorlib](https://colorlib.com/)
